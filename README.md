# HTML Learning Pages

A small collection of HTML and CSS practice pages. The files explore basic page structure, headings, text, lists, spans and divs, images, fonts, and stylesheet linking.

![Puzzle image used by the practice pages](puzzle.png)

## Pages and assets

- `index.html` — introductory markup exercises
- `3rd.html`, `4rth.html`, and `jhgf.html` — additional page experiments
- `style.css`, `style2.css`, and `style3.css` — page styling examples
- `fonts/`, `m/`, and the root image files — local font and image assets

## Run locally

Open `index.html` in a browser. Open the other HTML files individually to view each exercise. Keep the stylesheet, font, and image paths in their current relative locations.

## Built with

- HTML5
- CSS3
